# Plan: Clean history and push as new repo

## Goal
Remove all prior contributor history and publish as a fresh repository under Clive-bixby.

## Steps
1. Delete `.git` directory entirely (`Remove-Item -Recurse -Force .git`).
2. `git init` (default branch main).
3. Set local identity: `git config user.name "Clive-bixby"` and `git config user.email "<user's email>"`.
4. `git add -A` (respects updated .gitignore).
5. `git commit -m "Initial commit"`.
6. `git remote add origin https://github.com/Clive-bixby/jobs-auto-apply.git` (if not exists).
7. `git push -u --force origin main`.

## Validation
- `git log --oneline` shows single commit by Clive-bixby.
- `git shortlog -sn` shows only Clive-bixby.
- GitHub repo shows one commit.

## Risks
- Force push overwrites remote; acceptable since repo is new.
- Ensure no personal data committed (gitignore covers config.yaml, profile/, data personal files).
- Need user email for commit identity.
